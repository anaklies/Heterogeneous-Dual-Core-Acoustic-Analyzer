# 可复用技能包

本目录从项目研发中的数据遗漏、版本混用、边界判断和调度开销观察提炼方法，可用于其他FPGA、HLS及嵌入式项目。

|技能|适用场景|使用方法|已验证效果与边界|
|-|-|-|-|
|evidence-validation|比较黄金与实际结果，核对交付哈希|阅读SKILL.md；运行scripts/verify.py|自测匹配/不匹配/长度错误/非法数值及路径越界；本项目核对完整交付哈希。不是板测工具|
|bounded-fpga-optimization|功能不变的性能与资源优化|使用提示词模板，固定输入和基线，只改一个变量|源自64→512分片预算的7组板测；不保证其他项目同样收益|
|layered-feature-audit|算法已存在但主机不能调用，长流程/事件排错|按PL→PS→协议→PC四层检查表定位|源自45/51项计数与输入参考补齐记录；状态区分可复用，但实际通路仍需目标设备验证|
