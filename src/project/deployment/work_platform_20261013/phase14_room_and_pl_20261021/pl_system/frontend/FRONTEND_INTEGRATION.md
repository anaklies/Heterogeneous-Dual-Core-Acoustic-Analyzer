# 真实PCM前端及缓存连接记录

日期：2026-10-22。开发候选，不是整板验收或烧录文件。

## 本次实际实现

`candidate_pipeline/acoustic_frontend_split.cpp` 是当前前端候选。输入为11776×6个signed24-in-signed32 PCM，调用原厂商512点FFT和既有1536点混合基合成，生成真实STFT及15麦对网络特征。没有输入预制方向、空间评分或真值。

同配置、同会话、相邻4608采样的窗口复用前窗t12～26，作为当前t0～14；只计算当前t15～26。因此首窗162次变换，稳态72次变换、复用90次。频点、通道顺序及特征Q11规则不变。没有跨窗口复用GRU隐藏状态。

STFT、幅度临时量和量化对数工作区均使用显式DDR参数。幅度临时量不再与完整对数数组一起分配为两个40KiB片上数组。对数特征每通道只量化一次，所有麦对复用；固定频率特征直接以整数生成，麦对相位仍按原定义计算。

HLS首次将动态三角麦对循环展平时发生工具原生崩溃；改为固定15麦对和1701项独立内核后构建成功。工具故障日志保留，不当作算法测试失败或成功。随后将AXI读回与本地PCM范围判断分离，修复报告中明确的握手到提前返回的组合关键路径。

- 两个已有M房间PCM相邻窗口，不生成新房间、不训练网络。
- C模型冷/热窗口均与旧特征C参考逐位一致；配置、会话、版本、窗口大小、采样号变化会禁用复用。异常PCM和计数溢出保持无效。

- `frontend_lease.sv` 的58项RTL检查通过，包括背压、银行切换、token回绕、配置变化、旧完成拒绝、故障、超时和受控恢复。

目标时钟13.333ns，不确定度3.6ns。最后一项达到HLS的有效延迟预算，不是实现后WNS/WHS。最大周期包含冷启动和保守路径界，不是热窗口实测周期；禁止直接宣称连续10Hz。

前端已经包含1536FFT，不应再把单独的1536FFT核加算一次。普通声学分析的2048FFT是另一个数值契约，目前没有因此自动完成。

NN新增 `../nn_window/candidate_conv_shared/`，卷积输出与深度卷积输入共用同一组12银行RAM。对上一候选，BRAM18K216→200、LUT21804→21592、DSP85→83；76576个整数输出及18个计数逐位一致。原候选保留。

当前独立HLS规划若把新前端、NN及方向解码同时常驻，合计65492 LUT、150 DSP、273 BRAM18K，尚未含板级和其他P0。它不是整板实测资源，且暴露了面积风险。因此对新前端启动首次Vivado OOC综合，检查真实资源；结果以验收JSON及报告为准，不以此合计宣称能装入7020。

首次Vivado OOC综合已经完成，前端实际综合结果为14210 LUT、15231 FF、45 DSP、21.5 BRAM36等效（15 RAMB36加13 RAMB18），未解析黑盒为0。
综合后内部时序估计WNS+4.325ns、WHS+0.194ns，TNS/THS为0；但没有放置布线，OOC时钟源未指定，168个输入/376个输出没有板级外部延迟。
这些是独立核综合数据，不能称为整板时序闭合，也不能与其他核的HLS数字混合成一个实测整板报告。
综合本身只执行一次；原脚本在提报告时引用不存在的run对象，随后直接打开已生成DCP补提报告，没有重做综合。

## 缓存、内存和故障契约

`DDR_LAYOUT.json` 给出25个互不重叠区域，位于一个至少8MiB的DMA安全保留区内。这里只定义布局，没有实际申请Linux内存。

`frontend_lease.sv` 只管理两个STFT缓存银行和一条前端命令：

- 命令背压时参数保持；银行只在匹配成功完成后切换。
- 搬动DDR区域、改变会话/配置、采样不连续均禁止复用旧缓存。
- 等待下游接收完成通知时，禁止新前端任务覆盖银行。
- 超时不立即复用缓冲、不撤销已发出的命令、不自行复位活动AXI主机。
- 必须等待匹配完成安全排空，或收到真正的总线静止/共同复位确认，才可恢复。

**以下仍需实际连接，不能由本模块代替：**

1. 原始PCM环形缓冲到不可变窗口的采集/拷贝，以及三组PCM、特征、方向向量槽的全局所有权。
2. HLS AXI-Lite命令写入与完成读取桥。`command_ready`必须表示命令已安全接收；`done_error`必须合并内核错误和AXI RRESP/BRESP。
3. 真正的AXI未完成事务计数/静止检测。不能把`bus_quiescent_ack`常量接1。
4. 共享AXI仲裁、缓存一致性、PS/PL原子邮箱、姿态与传感器链。
5. 稠密频谱窄带/覆盖率质量守卫、常规2048谱分析及其余P0/P1/P2后端。
6. 当前输入通道读取仍是交错PCM的跨步访问，实际DDR停顿可能影响节拍；HLS周期不能代替总线吞吐验收。

元数据commit字不是总线栅栏。只有HLS完成、相关读写响应成功并匹配token/配置/会话后，才能把该帧交给下游。此前的profile_scheduler局部reset信号也不能直接复位仍有AXI事务的主机。
