# 分析仪候选接口

PS 主邮箱沿用 0x43C20000；分析核 0x44A30000；新增普通共享 FFT
0x44A40000。旧自动 DOA、NN 及专用前端地址不在本候选 BD 中映射。
不允许旧客户端把旧自动定位命令发送到其他新功能。所有 AXI 是片内接口。

P0 采集/电平/频谱/质量，P1 当前订阅组周期分析及开启后的事件服务，P2
单个按需高级任务。原位号保留，bit8 禁用，不把静态条目计作独立算法。
帧界配置与单一运行时持有者仍需完成物理集成。PS 和 PL 不得同时操作
同一核/缓冲；先前已经在飞的 AXI 不能被局部复位强行撤回。

analysis_job_bridge.sv适配已验证的旧命令桥：只允许0x44A30000的10参数与
0x44A40000的6参数，参数偏移逐项核对，完成后等目标DMA排空，再读取
真实status寄存器0x60/0x40。JOB无DDR路由，不能沿用旧DDR metadata读取。
249项短RTL检查通过；适配器尚未接进物理调度器，不能恒定拉高DMA空闲。

analysis_packet.h 是 PS/PC 新协议字段契约，不是假装已经接入 Linux。
线格式按小端逐字段编码，禁止直接发送编译器布局的 struct。
能力查询目前 actualHardwareCapabilityMask=0、algorithmVersion=0，直到完整
功能和整机验收才逐项开启。非法/旧配置、超时、DMA 错误和缺口必须使 valid=0。

新 FFT 支持 2048 点去均值实数 Hann、复数前向、复数逆向及交织 signed24 PCM。
FFT 输入/输出均为 DDR 字，stride 以32位字为单位；输出为4096个 float32
实虚交织。正向不缩放、逆向除2048。实数 PSD 只取前1025复频点，使用
周期 Hann 的窗和1024、窗能量768，单边端点不乘2。
同一FFT可复用但不得并发重入，长P2需要在有界FFT任务间让出P0。

规划预留32MiB DDR：前16MiB为PCM环（32字节/六通道采样组，含64bit样本号），
后16MiB为分析arena。环可覆盖约10.92秒，8秒事件约12.288MB。
这是布局需求，不是已分配内存；Linux必须通过reserved-memory或DMA分配
取得真实物理区，禁止使用malloc虚拟地址或随意覆盖系统DDR。
环覆盖保护和事件区钉住/复制、全局槽池尚待接通，不宣称前后录音已在板上生效。

PS负责WAV、日志、网络待发送队列和可选LCD彩蛋，不负责核心声学算法。
网络/磁盘慢端必须独立队列，不能阻塞PCM。断线后保留序号/缺口计数，
待完整服务连接验收。LCD播放器失败不能成为分析仪启动失败条件。
lcd/附可选systemd服务文件，未安装或启用。默认用spidev，不默认使用
可能大量忙等的/dev/mem备用路径。现有BD保留SPI0/EMIO；物理顶层还需
核对LCD球位、GPIO输出和SPI SSIN高电平，QEMU不证明屏幕已点亮。
