# 共享分析核：保留13项原语，新增7项阶段

所有数值为规范化数字量或明确指定的IR/PSD，不是绝对声压。
a/b/out是同一个float32 DDR arena内的字偏移，不能输入输出重叠。
根入口以64bit长度算术拒绝越界和别名；status非零时整次结果无效，
不能使用已经写出的部分结果。旧13项数学公式不改，未重复旧3137项。

|op|阶段|输入与输出|
|---|---|---|
|1|六通道电平|n×6规范化PCM；每通道8字段|
|2|Hann谱缩放|n点未缩放复FFT；单边幅度/PSD/频点功率|
|3|谱描述/主峰|n个功率或同网格PSD；能量、质心、平坦度、主峰|
|4|谱平滑|奇数宽度，边缘有效点归一|
|5|互谱/相干/相位|配对多帧复谱；不能把单快照相干当可靠证据|
|6|能量/正谱通量|同网格前后功率；不是完整事件服务|
|7|有限M谱峭度|多帧功率；保留重叠窗偏差限制|
|8|频带积分|PSD及左右频带边界；按中心频点积分|
|9|归一自相关|单通道；滞后观察，非自动定位|
|10|DAS合成|复谱及已生成的权重；不含导向计算/全图调度|
|11|参考dB差|两个有效同网格正功率；外部检查测量元数据一致|
|12|滑动功率和|sum+new-old；历史环由调度器提供|
|13|解析信号模|复解析信号；不含Hilbert构造和IFFT调度|
|14|峰值保持更新|a旧保持、b新功率，out=max(a,b)|
|15|频漂|a频率、b递增秒；out每帧[Hz/s,valid]，首项无效|
|16|谐波带积分|a PSD、b用户/上游基频生成的中心列表、frames中心数、df频宽、parameter半带宽；每带[峰频,能量,对第一带比]及有限THD/valid|
|17|IR反向能量积分|a已对齐IR，parameter噪声功率、df采样率；输出[能量,归一dB]；不含噪声估计和自动对齐|
|18|清晰度|a已对齐IR、df采样率；C50/C80/D50及独立有效标志|
|19|衰减拟合|a归一dB曲线、b=[上界,下界]、df采样率、parameter最小R²；RT60/斜率/R²/点数/valid/时长|
|20|自相关基频候选|a已归一自相关、b=[最低Hz,最高Hz,相关门限]、df采样率；频率/周期/相关/valid|

新增各阶段没有伪装成完整谐波、基频、RT60服务。op16仍需要正确基频与
积分窗口；op17-19仍需要有效IR、噪声尾部判断、拟合范围及不适用标志。
op20目前只完成相关峰候选，不是未知多源自动F0恢复。

验证：results/extended_math.json为11组新增数值对照、7个异常输入/别名及1个无效拟合检查；
analysis_csim_review_fixed.log为厂商内存C模型峰保持、积分、拟合及别名拒绝。
不是RTL联合仿真或实际DDR带宽测试。HLS总延迟含动态DDR循环，未给确定上界；
不得据FFT内部周期就宣称整机10Hz。
