# 共享硬件结构决策（2026-10-23）

选择：实际共享FFT/IFFT + 有界PL标量执行核 + 不可变窗口/DDR槽 + P0/P1/P2统一调度。没有NN/自动DOA，也没有把DSP转移到PS。

## 测量与取舍

1. 对旧大分支HLS核做过一次hierarchy探针：LUT估计33397→32236，仅3.5%收益，拒绝继续优化这一路。未为该探针跑整板。
2. 新标量核以寄存器RAM、共享浮点运算和最多64条指令分片替换大量功能选择/控制复制。Native C新增15项数学/上下文测试和7项错误边界检查通过。最终HLS ABI为四输入参数、status0x30。一个程序执行器不代表全部声学服务已完成。
3. `analysis_runtime` 实例化两套真实HLS导出及实际AXI活动监测。2026-10-23组合OOC综合（xc7z020clg484-2）：22224 LUT（41.77%）、21070 FF（19.80%）、58 DSP（26.36%）、52 BRAM36等效（37.14%），520控制集，无锁存器；综合WNS+5.186ns/TNS0，WHS+0.157ns/THS0。
4. 初次组合发现窗口RAM模板不受支持，导致48492 LUT及22335存储LUT，后者超过器件17400容量。按标准同步RAM模板分离存储读寄存器和旁路/银行选择后，相同功能降至22391 LUT、存储LUT1291，其中分布式RAM528、SRL763；BRAM等效24→52。修复后同一串行I2S数据的12288字/768burst回归通过。原失败报告保留在results/runtime_before_ram*.rpt。

以上是**包含真实采集/两共享计算核/调度/监测的子系统综合**，不含PS7、HDMI、板级DDR互连、任务4全部服务程序、事件/传感器系统。没有布局布线，所以不提供最终Slice装箱率，不把综合时序当成整板实现后时序。不得与旧45296-LUT整板候选直接做同功能降幅比较。

此结构为后续功能共享提供了实际余量，避免将52条记录实现成52套独立IP。但尚不能据此保证所有功能最终可放入7020：相位/三角函数、完整服务程序、周期、板级互连及最终布线仍须按剩余任务确认。

## 52项如何复用

完整逐项表见FUNCTION_EXECUTION_MAP.csv，原始清单及历史软件参考未改。基本电平/复谱/逐窗PSD已接入基础共享核；Welch/平均/保持/倍频程等依赖共享谱和标量状态；周期/包络/倒谱依赖共享FFT/IFFT；互谱/相干/延迟依赖双通道谱和标量状态；人工定向分析与房间实验需要后续完整服务程序及必要共享相位原语。不得把通用ADD/MUL或原历史原语标成已完成全部功能。

## 当前硬边界

OOC有独立compute/audio时钟及异步FIFO；CDC报告219端点均识别Safe，无Unsafe/Unknown，但这是综合阶段。板级需实际时钟、I2S I/O时序、Gray总线偏斜约束、复位释放以及放置布线复核。控制端口是工程内部接口，不是7020物理封装的127组引脚。不能直接生成可烧录成品。

最终资源对应显式FFT流接口及完整输入预验证后的版本；22391 LUT是RAM模板修复后的中间结果，21951 LUT是尚未补齐非法复数帧恢复的中间结果。均不可替代最终22224 LUT报告。
