# 真实数据与统一调度接口

本目录是 Phase15 的隔离候选，不覆盖历史正式源码。自动 DOA/NN/XYZ 不在本候选中。

## 实际连接

`analysis_runtime.sv` 实例化实际 `stream_fft2048`、`scalar_engine`、两个 AXI 活动监测器和 `audio_pipeline`。后者连接已有 I2S 收发、异步 FIFO、不可变窗口、窗口 DMA、原始 PCM 环和统一调度器。控制寄存器由 PL 调度独占，PS 不能同时直写 HLS 命令寄存器。

运行接口有四个独立 DDR 主端：raw、win、fft、scalar。它们必须经板级 AXI 互连接到 PS HP/DDR；当前综合为本子系统 OOC，不含 PS7/HDMI/板级互连。实际内存响应连接到 guard；未用常量假装 DMA 空闲。接口含配置、session/config、frame、首样本号、结果槽及错误位。后续任务6再实现PS寄存器映射。

## 数据格式与内存所有权

- 六路 INMP441 使用相同 BCLK/WS，左声道，24位有符号 PCM。音频时钟参考49162010Hz，64时隙×16分频，实际采样率48009.775390625Hz。不是悄悄假定恰好48000Hz。
- 四个PCM槽：相对arena字节地址 `slot*0x10000`。每槽6×2048个signed32，24位符号扩展，按通道平面排列。
- FFT槽：相对arena字节地址 `0x100000+slot*0x40000+channel*0x8000`。
- 每通道7179个float32：0..4095为2048点完整复谱交错；4096..7170为1025组三元组（幅值、PSD密度、bin功率）；7171..7178为RMS、峰值、峰峰值、均值、dBFS、波峰因数、削顶数、有效位。
- 实数模式去均值后用周期Hann窗。幅度按窗和1024缩放；PSD按fs×768缩放；单边端点不乘2。电平是窗前原始输入测量。静音dBFS占位0但有效位0，不能显示成有效0dBFS。
- 这是逐窗periodogram/复谱，不等于已经完成Welch历史平均或无限STFT缓存。
- 前2MiB只读基础槽；后台输出、程序、上下文必须位于2MiB之后。配置的arena必须是独占保留DDR，不与原始录音环重叠。
- P0仅在六通道都完成且全部DDR响应返回后发布快照。慢消费者不阻塞采集；重用会清除快照有效位并增加未消费覆盖计数。PS读前读后核对slot/frame/session，使用DMA一致性或非缓存映射。
- P1/P2首次运行各自固定一个已完成源槽，跨分片保持只读租约，直到done/错误/配置取消。分配器不能覆盖这些槽；两个后台任务最多固定两个槽，保留两个供采集及P0。

## 调度

基础分析采用2048点无重叠窗口，6通道顺序复用同一个FFT。每2个已完成窗口发布一次基础结果，理论11.721Hz；每通道谱帧23.442Hz。50MHz计算时钟下窗口预算2132900周期，两个窗口约85.316ms。此前512hop/9窗是未完成周期验收的候选，不作为当前运行配置。这里改变的是分析刷新/重叠策略，采集与原始PCM环仍连续。事件特征、检测、双bank原音留证和MMIO读取已进行联合RTL验证；测试采用缩短保留区，未作实物验证。旧49.162MHz系统的4718592周期不能直接照搬50MHz子系统。

P1按周期触发，P2按当前配置启用。二者在P0作业边界以普通64条、上限512条PL标量指令分片；轮流获得空闲时隙。配置可使P2页面开启时暂停P1。配置只在没有在飞命令及FILL槽时生效；旧READY丢弃，旧上下文取消。恢复期间不接受配置。服务目录已有可执行描述符/程序生成器及分级数值证据；不代表各完整服务均通过RTL或板卡时延验收。

后台调用九参数ABI：arena字节基址、descriptor字偏移、arena字数、source_slot、session、configVersion、sourceFrame、sampleLow、sampleHigh；标量状态位于0x58。FFT为七参数ABI，状态位于0x48。参数偏移按实际HLS驱动头核实，不照搬旧IP。

P1/P2各配置一个4项描述符表，16字/项；调度自动选择`base+16*source_slot`。相对LOAD/STORE的word2=1时，地址相对描述符readBegin/outBegin；只允许读取固定源槽，不能越读其他实时槽。

上下文绑定session/config/program、代码与读写范围、运行generation及source_slot。主机不得在作业期间修改代码、描述符、输入或上下文。更新先停新任务并排空，再提交新配置及generation。

## 故障与证据等级

超时不撤回已发起的AXI。迟到ready不得启动超时前尚未接受的命令。窗口DMA必须收到B响应才提交；错误窗口保持无效。共同恢复确认必须真实代表总线及DMA主设备已排空/共同复位；协议损坏需要共同rst_n，不能把ACK常接1。顶层还检查所有内存guard空闲及控制/导出端无未完成请求。

当前已验证：真实串行I2S到DDR；同一PCM的FFT/PSD/电平C数值；缩放控制级持续调度、固定源租约、切换、超时、背压及恢复；实际核组合综合。上述分级证据不等于完整RTL连续PCM或实板10Hz。实测周期及尚未关闭项见PROGRESS.md。
