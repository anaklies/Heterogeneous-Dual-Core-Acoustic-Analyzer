# 神经网络硬件吞吐与ROM结构修复

日期2026-10-21。只修改本目录；原J权重、fixed整数黄金、历史PL及启动文件不变。

## 实际完成

V1：12输出通道卷积，一次缓存输入，90个元素依原顺序累加。HLS核心II=1，首卷积170990周期，对比旧HLS最坏11115301约65倍；这是HLS估算比较，不是实板测速。

V2：共享矩阵支持point/embed/GRU两条仿射/phase/support，另有12通道depth。纯激活后处理与计数提交分离，避免并行对同一统计值读改写。两份完整15麦对黄金的76576个int16值和18计数逐位一致。但HLS把192位ROM按每lane复制12份，又在自动outline中复制矩阵块3份，资源超限，明确拒收。

V3：每个权重字显式读取3×64位，随后展开12lane；567作业调度器中只有一个matrix12调用，强制真实共享。修复大规模ROM复制，221BRAM18K。V4进一步删除多余10368元素卷积结果缓存（输出已是父级局部conv RAM），11处复制循环流水。资源205BRAM18K，保留所有失败候选，未修改网络结构或精度。

全部并行候选使用相同signed16权重、原Q格式、原舍入/饱和与非线性LUT。C全网比较不是硬件通过；各自C_EQUIVALENCE.json保留精确范围。

## 一次必要的整数RTL协同仿真

V4在20.341ns配置下只运行已有speech输入的第一个麦对：**PASS，实际373202周期，6399个phase/support/hidden输出加18计数与原整数黄金零差异**。
输入并非PCM，而是冻结的Q11 pair_features；没有运行全部15麦对、globalactivity/count或空间解码。只有一次事务，II无法测量，报告NA。
使用HLS自动生成AXI模型，没有随机停顿、真实DDR争用或CDC；104秒完成，没有重跑旧完整PCM长仿真。
若15麦对成本均相同，合计5598030周期，在49.162010MHz约113.87ms，已超过96ms预算；因此不能批准当前捕获时钟上的完整10Hz。

## 静态567作业证据

JOB_SCHEDULE.csv逐个列出432个point、27个embed、各27个GRUinput/hidden/phase/support作业。
对应matrix12的HLS端点可复现groups*(columns+34)+1，合计149391周期；MAC输入发射79056周期。它仅覆盖矩阵块，不含conv/depth、拷贝、GRU非线性、AXI和全网globalhead。绝不把这一局部数值当整机周期。
ACCUMULATOR_PROOF.json对实际所有量化权重、所有signed16激活计算abs(bias)+32768*sum(abs(weights))，最大只需36个signedbits；48位累加不会因从原64位缩小而溢出。RTL协同仿真也覆盖真实48位实现。

## 独立75MHz计算时钟的有界可行性探针

只修改clock=13.333ns；没有改变采样时钟、采样率、物理传播或算法源码。
HLS估计周期12.504ns，资源205BRAM18K、56DSP、13138FF、25973LUT。仅估算，不是实际布线Fmax。
对比调度：matrix组开销由34变36，2052组增加4104周期；27个GRU非线性块由912变1008增加2592周期。
若其余路径与50MHz单次模型一致，推导单麦对379898周期、15麦对约75.98ms，给96ms留下约20ms。这是**条件性计算预算**，未执行75MHz RTL仿真或全15麦对持续输入，不能宣称10Hz验收通过。
未来需要PSFCLK或PLL提供独立computeclock，并验证CDC、DDR、完整前后处理、布局布线和长序列。不允许仅把日志单位换成75MHz就宣布产品变快。
