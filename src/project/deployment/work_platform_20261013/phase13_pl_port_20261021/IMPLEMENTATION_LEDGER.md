# 当前冻结算法的PL迁移实施记录

本轮继承Phase12M/N软件范围，不覆盖任何历史PL、Bitstream、XSA或启动包。

已核实：旧整板为MUSIC 0A，不包含当前SRP-DNN。必须更换算法核，不能用旧资源报告宣称新算法已放下。当前44登记项是共享算法/接口功能，不是44个独立IP。

## 执行任务

- 复用六路I2S、PS7/HDMI、传感器驱动及既有黄金；新的RTL/HLS/测试只写本目录。
- 控制：P0/周期P1/订阅P2、PS+PC联合订阅、帧原子配置、故障隔离/有限重试。
- 计算：共享乘加与FFT1536准确路径；模型权重导出和定点误差检查；基础分析算子向可综合实现转移。
- 接口：AXI-Lite控制/能力/状态，真实PCM/分析结果的DDR通路与版本协议；不返回未实现算法的伪数据。
- 环境：SHT30低频单次测量、湿度/气压有效性、声速模式、姿态/安装轴及异常回退。
- 实测：局部数值/RTL回归、综合资源与时序；通过后才接整板。未接入或未通过项目保持未通过。

## 重大已知集成缺口

旧BD的HP0服务HDMI VDMA，目前音频核心只有GP0邮箱，没有音频大容量DDR DMA。
新模型的1536/hop384 FFT不等价于旧2048 FFT；旧85频点输出不能替代新63频点及完整分析谱。
本轮先用真实综合证据选架构；时分关闭不会释放已实例化逻辑，资源节约来自实际共享。
