# 独立接线版：六麦时钟、SHT30及IMU分线

接线修订2，2026-10-26。**只有配套的新BOOT.BIN/Bitstream生成并通过实现门槛后才能按此表换线。旧整板包仍使用旧的公共时钟和公共I²C接法。**

40针J1有34根信号脚；本版使用22根，剩12根。所有信号为3.3V电平，电源和地可共用。

- 39/40为3.3V；1/37/38为GND；**2脚为5V，不接信号或麦克风VDD**。以板子J1的1脚标记确定方向，勿镜像数针。
- 六个麦克风的L/R全部接GND。每个麦克风自己的SD、SCK、WS都单独走到对应针，彼此不在板外并接。
- 六组SCK/WS在PL内部来自同一个同步源，不生成六套独立采样时钟。外部路径仍会有小的物理偏斜，不宣称零偏斜或已实物测量。
- SHT30和IMU的SCL/SDA不再板外并接，各支路分别上拉至3.3V；模块若已有上拉，应检查总阻值。
- 两组I²C物理支路内部复用同一个低速事务控制器，按已锁存的地址轮询；未选中的支路释放，输入只读取选中支路。不是将两个SDA仍在PL内部直接短接。
- 当前适配SHT 0x44/0x45及IMU 0x50协议。驱动采用这三种地址中已锁存地址的bit4选择物理支路；不得不改驱动就随意换成其他地址/协议的IMU。
- 头针/封装球号对应关系核对了用户提供的V1.0原理图第5页和40PIN J1图；实际方向、电压设置仍需通电前核对。

PC/PS协议与网口48120/48121保持兼容；本交付活动目录为45项，六项空间功能已停用。原接线修订记录中的51项计数不作为本版功能数量。无需重写PC；必须更新PL配置和包含它的BOOT.BIN。

## 启动与回退

新整板包内的sd/文件放入FAT32启动分区根目录；断电后选择SD启动（按手册：ON为0，SD为11，即两位OFF），再通电。BOOT.BIN已包含新的PL，不需要分别给PL和PS下载。image.ub中的PS程序保持不变。

长期QSPI/eMMC方案仍需先备份、核对实板启动路径再操作；本次不擦写。第一次先用SD，恢复时关机取卡并恢复QSPI启动，可回到未被改动的出厂系统。不要把新接线配旧BOOT.BIN，也不要在转接板上把这些独立输出重新短接。

变更源码位于rtl/，原正式和已冻结版本不被覆盖。短I²C检查只验证选通信号、非选中支路隔离与无应答退出，不等于传感器实物验收；不重测PCM/DSP逐帧算法。
